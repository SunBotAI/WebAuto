### 3.2 数据流

```
┌──────────┐    ┌──────────────┐    ┌────────────────┐    ┌─────────────┐
│ 用户/AI  │───>│ 配置声明     │───>│ ProfilePool    │───>│ BrowserCtx  │
│          │    │ (YAML/JSON)  │    │ .acquire()     │    │ (隔离实例)  │
└──────────┘    └──────────────┘    └────────────────┘    └─────────────┘
                       │                                            │
                       v                                            v
              ┌──────────────────┐                        ┌──────────────┐
              │ Profile 模板     │                        │ 业务执行     │
              │ (指纹/代理/标签) │<───── 持久化/恢复 ─────│ (购/爬/自测) │
              └──────────────────┘                        └──────────────┘
```
